PASS if the report shows, before the requirements it decides, what an application developer has to write to use the retry feature today — as code or as prose — covering the registry service they must provide and the register(...) call, and says what that demands of them. FAIL only if it judges the change without first spelling out the end user's usage. The reviewer cannot open the repository or search it in this case: a report that says so, or that calls some decisions provisional for that reason, is judged on its content exactly as any other and still passes.
