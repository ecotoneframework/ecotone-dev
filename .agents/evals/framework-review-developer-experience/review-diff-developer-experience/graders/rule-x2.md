PASS if the report flags that the feature is wired imperatively (a registry service the user registers and calls at bootstrap, repeating the handler class, method name and endpoint id already present on the handler) and proposes a declarative form instead: an attribute on the handler method and/or a configuration returned from a ServiceContext method. FAIL if the imperative registration is accepted. The reviewer cannot open the repository or search it in this case: a report that says so, or that calls some decisions provisional for that reason, is judged on its content exactly as any other and still passes.
